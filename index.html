🌀 Endless Labyrinth

Navigate the glowing orb from the green start point to the pulsing portal exit. As soon as you solve one maze, you immediately warp into the next unique, procedurally generated maze!

Controls

  • Move W A S D or Arrow Keys
  • Toggle Camera Space or C
  • Path Hint H
  • Switch Theme T
  • Toggle Sound M
  • Restart Maze R

Guaranteed Solvability

Each maze uses spanning-tree depth-first branch generation, mathematically guaranteeing that every single maze has a valid, unbroken path to the exit, with maximal topological distance between start and finish.
